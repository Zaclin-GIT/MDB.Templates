# MDB.Templates

Project templates for [MDB Framework](https://github.com/Zaclin-GIT/MDB) — a Unity IL2CPP modding framework.

Each template lives on its own branch. Clone the branch you need to get started.

## Templates

| Template | Branch | Command |
|----------|--------|---------|
| MDB Mod  | [`mdbmod`](https://github.com/Zaclin-GIT/MDB.Templates/tree/mdbmod) | `git clone -b mdbmod https://github.com/Zaclin-GIT/MDB.Templates.git MyModName` |

## Quick Start

```bash
git clone -b mdbmod https://github.com/Zaclin-GIT/MDB.Templates.git MyModName
cd MyModName
```

Then follow the setup instructions in the branch's README.

## Prerequisites

- [MDB Framework](https://github.com/Zaclin-GIT/MDB) injected into the game at least once (to generate the SDK)
- .NET Framework 4.8.1 targeting pack (installed with Visual Studio)
- .NET SDK 8.0+
